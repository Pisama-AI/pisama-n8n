# Promo v2 creative brief

## Subject and audience

Subject: the PISAMA closed-loop evaluation system for n8n workflows.

Audience: automation builders, AI platform engineers, and engineering leaders who need evidence that an agent workflow is safe to release.

Single job: make the viewer understand how an n8n execution becomes reviewed, immutable release evidence.

## Visual system

- Ink: `#090a09`
- Carbon: `#151815`
- Paper: `#f4f5f0`
- Muted gold: `#e5b84b`
- Evidence teal: `#75b9aa`
- Fault coral: `#dc786a`

Display type uses Georgia with generous spacing. Interface and explanatory type use Arial. Evidence values use the system monospace face.

The layout is dark, flat, and quiet so the real n8n and Pisama interfaces remain the visual focus. Cards use hairline borders and large internal spacing. Motion is limited to fades, line progress, cursor travel, and smooth camera crops.

## Signature

The signature element is a small evidence packet that travels through the five closed-loop stages: capture, detect, review, freeze, and score. It starts as an amber execution record and finishes as a checked, immutable score record.

## Deliberate risk

The opening withholds the product name for the first sentence and leads with a product truth: a successful workflow can still fail the user. This earns attention before introducing the system.

## Self-critique

The first design pass used generic section numbers and presentation-style title bars. V2 removes those bars. The sequence is encoded by the evidence packet itself, while chapter labels appear only when the product context changes.
